# 📁 Holy IDE ✨

A personalized, lightweight, web-based Integrated Development Environment (IDE) custom-built for my college crew. Designed to strip away the bloat of traditional heavy editors and provide a fast, accessible, and distraction-free workspace for late-night coding sessions.

## 🚀 Features

- **Instant Code Execution:** Write and test scripts directly from the browser without tedious local environment setups.
- **Tailored for the Crew:** Built specifically with custom configurations, themes, and shortcuts optimized for our college workflow.
- **Minimalist & Clean:** Fast load times, slick UI, and low resource usage—perfect for quick logic testing or intense coding grinds.
- **Syntax Highlighting:** Clean, readable text editing that makes tracking down bugs easy.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Custom Dark Theme optimized for midnight productivity)
- **Core Engine:** JavaScript (ES6+)
